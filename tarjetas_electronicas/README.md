# Tarjetas Electrónicas

Esta carpeta contiene todos los diseños de las tarjetas electrónicas del proyecto **Red Sismica del Austro**.  

Cada proyecto tiene su propia subcarpeta, que incluye:

- Esquemáticos (SCH)  
- Archivos PCB / Layout  
- Archivos relacionados de diseño  

Proyectos incluidos actualmente:

- Acelerógrafo  
- Digitalizador de Geófono  
- Colimadores  
- Elongámetros  
- Termocuplas
