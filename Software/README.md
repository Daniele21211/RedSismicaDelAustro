\# Software



Esta carpeta contiene la documentación y guías relacionadas con el \*\*software/firmware\*\* utilizado en las tarjetas del proyecto \*Red Sísmica del Austro\*.



\## Contenido



\- \*\*Programming guide.pdf\*\*  

&nbsp; Guía de grabado/carga de firmware (herramientas, pasos y consideraciones de programación).



\- \*\*Piezometer Software design.docx\*\*  

&nbsp; Documento de diseño del software/firmware correspondiente al módulo \*\*Piezometer\*\*.



\- \*\*Thermocouple Software design.docx\*\*  

&nbsp; Documento de diseño del software/firmware correspondiente al módulo \*\*Thermocouple\*\*.



\## Notas

\- Los documentos se mantienen en esta carpeta para asegurar trazabilidad y respaldo del proceso de programación/carga de firmware.
